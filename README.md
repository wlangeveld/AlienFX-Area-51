# AlienFX-Area51

This program controls the FX lighting for Alienware Area 51 desktops using the USB `187c:0550` controller. 

## Acknowledgements & History
This program was originally derived from [AlienFX-Aurora](https://github.com/Freedom9339/AlienFX-Aurora) by Freedom9339, which itself was built on top of the [humanfx](https://github.com/tiagoporsch/humanfx) project by tiagoporsch.

The code in this version has been completely refactored to correctly map the 9 physical lighting zones into 4 logical zones for the **Alienware Area 51 R5 (and likely R4)**. These major refactoring changes and updates were generated by **Gemini 3.1 Pro** in **Google Antigravity** running locally on Ubuntu 24.04 on the Alienware Area 51 R5.

### Release History
* **v1.1.0** - Added Mathematical 2.2 Gamma Correction to the color parser to prevent secondary color "washout" on linear LED hardware. Fixed abrupt shutoff bug during "Breathe" mode.
* **v1.0.0** - Initial Area-51 Refactor (mapped 4 logical zones, renamed application).

## Dependencies

You will need the following dependencies to compile from source:
```bash
meson
libusb-1.0-0-dev
libadwaita-1-dev 
libgtk-4-dev
```

## Installation
To build and install the application automatically, just run:
```bash
./install.sh
``` 

This will compile the GTK4 application and install it to `$HOME/.local/share/AlienFXArea51`, alongside registering the `.desktop` application in your local environment.

To uninstall, run:
```bash
./uninstall.sh
```

## Testing Zones
Using the "Test Zones" button allows you to enter a range of zone IDs to find unmapped LEDs. These IDs are unsigned integers. If you manage to discover new mappings for different revisions, feel free to contribute them back!
